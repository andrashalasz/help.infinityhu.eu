Every document the company has filed is here — contracts, permits, incoming and outgoing invoices, bank statements, e-mail attachments, work sheets and HR documents.

You reach the screen under Document filing → Document list. You add a new document with the blue + Create button next to the title — that has its own chapter (Filing a new document).

How the screen is built up

From top to bottom the screen consists of: the Document list title and the + Create button, four tiles with the most important indicators, the toolbar (search, date, filters, views, export), the active filter bar, and at the bottom the table and the pager.

The top title bar

In the top left you read the Document list title with the current document count. Right next to it is the blue + Create button — this is where you start recording a new document. On the right edge a gear icon opens the view settings (column order, density).

The tile row

Four coloured tiles highlight the most important KPIs. One click also filters the table to that group; a second click switches the filter off.

  • Red tile — Expired documents

  • Yellow tile — Expiring soon (within 30 days)

  • Blue tile — Filed this month (with the change against last month)

  • Green tile — Awaiting approval

Item What it means
The toolbar From left to right: the global search field, the Filing date button, the Filters button (with a number bubble showing how many filters are active), the Views dropdown and the Export dropdown.
Active filter bar Below the toolbar, a blue bar shows your currently active filters as chips. The × next to each one removes exactly that filter. The Clear all link on the right removes every filter at once; the hit count is shown beside it.
The table The main area is the document table. Each row is one document, and the columns from left to right are: checkbox, two icons (Quick view and Open), Filing number, Document name + file name, Type, Filing book, Partner + tax number, Direction, Date, Expiry (colour coded), Status, Created by.
The footer On the white footer below the table: on the left the rows-per-page dropdown (10 / 25 / 50 / 100), next to it the pager buttons (previous, page numbers, next), then the text telling you which range is displayed.

Using the tiles

The tiles are the fastest way to focus on urgent or important documents. An active tile is marked by a darker background and a border.

Item What it means
Expired documents (red) Click the red tile — the list immediately shows only documents that have already expired. Go through it and decide for each row whether immediate action is needed (new contract, new permit, renewal). On expired rows the Expiry column is highlighted with a red background.
Expiring soon (yellow) Click the yellow tile to list documents expiring within 30 days. Use this proactively — you can start the renewal in good time, before anything lapses.
Filed this month (blue) Click the blue tile for the current month's filings. A mini chart on the tile shows the change against the previous month: a green up arrow with a percentage for growth, a red down arrow for a decrease.
Awaiting approval (green) Click the green tile for documents waiting for approval. If you are a manager and your name is listed as an approver, this is where the pending decisions collect. The average waiting time is shown on the tile in days.
Switching a tile off Click an already active tile again to switch the filter off. Alternatively, the Clear all link in the active filter bar removes every filter at once.

Search

The search field is on the left of the toolbar, with a rounded magnifier icon. Type what you are looking for — the list narrows as you type.

Which fields it searches

The search looks in every text field at once:

  • Document name and original file name

  • Filing number and serial number (for example EA/2026/000243 or R/2026/0000236)

  • Filing book name and document type

  • Partner name and tax number

  • Tags

  • The text of the note field

  • The name of the user who filed it

Item What it means
How multi-word search works If you enter several words separated by spaces, the system searches with OR. Any one of the words produces a hit. If you are looking for one specific document, use a distinctive word (a partner name or part of the filing number). If you want a topic, combine several keywords.
Accent-insensitive search The search ignores accents. Searching for aram also finds áram and Áram. Useful when you are not sure of the exact spelling.
Clearing the search Click the × icon that appears in the field as soon as you start typing. The search empties and the full list returns.

Choosing a date range

By default the list shows the whole of the current year's filings. You switch to another period with the Filing date button in the toolbar.

Choosing the date type

Click the Filing date button. First choose which date you want to filter by:

  • Filing — when it was filed (default)

  • Modified — the date of the last change

  • Expiry — the expiry date (only meaningful for expiring documents)

Item What it means
Setting the period After you choose the date type, a calendar popup opens. You can set the period in three ways. Use a preset button (Today, Yesterday, Last 7 days, Last 30 days, This month, Last month, This quarter, Previous quarter, This year, Last year) in the left sidebar, or click the first and last day in the dual calendar, or type the date in YYYY.MM.DD. format into the lower fields (for example 2026.03.15).
Apply and Cancel Click the blue Apply button to activate the period. The popup closes and the list refreshes. The Cancel button discards the change.
Clearing the date Once a date is set, an × icon appears to the right of the Filing date button. Click it — the range filter is removed and the default current year returns.

Detailed filtering

If the search and the date are not enough, use the Filters panel. Click the Filters button in the toolbar — a 400 pixel wide panel slides in from the right.

The sections of the panel

From top to bottom you can set the following filters:

  • Partner — autocomplete, type the first few letters of the name

  • Document type — multi-check, several types can be ticked

  • Filing book — single select dropdown (one book)

  • Direction — Incoming, Outgoing, Internal pills

  • Status — multi-check (filed, in progress, closed, expired, archived)

  • Expiry date — multi-check: Has expiry / Within 30 days / Expired

  • Filed by — dropdown

  • Note contents — free text search

  • Tags — tag pills, combined with OR

Item What it means
Applying the filters Set the sections one after another, then click the blue Apply filters button at the bottom. The panel closes and the list refreshes. The filters you set appear as chips in the active filter bar below the toolbar.
Switching filters off All at once: click the Clear all link in the active filter bar, or the red Reset button at the bottom of the panel. To switch off a single filter, click the × on its chip, or reopen the panel and untick it.
Cancel If you changed something in the panel but do not want to apply it, click Cancel — the panel closes and the changes are discarded.

The table and the rows

The document table offers many small conveniences for daily work.

Item What it means
Sorting by column Click the Date column header to switch the order (ascending / descending). The arrow icon shows the current direction. By default the newest document is at the top.
Row hover highlight Move the cursor over a row — its background turns pale blue. This makes it easier to follow which row you are looking at on a wide screen.
Document column Each row shows two pieces of information below one another. Above, in larger type, the descriptive document name given at filing; below it, in smaller grey type, the original file name with its extension.
Partner column Beside the partner's name, a second line shows the tax number. If the same company name occurs several times, the tax number tells them apart.
Item What it means
Colour coding of the Expiry column

  • Green background — more than 30 days until expiry

  • Yellow background — expires within 30 days

  • Red background — already expired

  • Empty — no expiry date set
Status column

Each status has a coloured pill: Filed (blue), In progress (yellow), Closed (green), Expired (red), Archived (grey). Archived only appears in the list if you tick it explicitly in the Filters panel.
Responsiveness

On smaller screens (laptop, tablet) some columns are hidden automatically (Filing book, Direction, Expiry, Created by) so the most important data fits. You can see the hidden data in the Quick view side panel.

Quick view and opening a document

At the start of every row, next to the checkbox, there are two small icons — shortcuts to the most frequent actions.

Item What it means
Quick view (eye icon) Click the eye icon — a side panel slides in from the right with all the document's data (filing number, document type, filing book, full partner details, project, cost centre, dates, tags, note, owner, file name, size) and a small preview. Close it with the × icon, or click another row's eye icon — that document then appears in the panel. You never have to leave the list.
Open (pencil icon) Click the pencil icon — the document's detailed editor page opens in a new tab. Here you can change any metadata, upload a new file version, see the full history (who changed what and when), add notes, archive the document, or share it with an external party by link.
Which one to use Use the eye icon when you only want to look at the document's data (who the partner is, when it expires). Open the pencil icon when you want to change something or download the original file.

Bulk actions

You can handle several documents at once by selecting them. This is useful for downloading a month's material for the accountant, or putting the same tag on many documents.

Item What it means
Selecting Tick the checkboxes on the left of the rows. As soon as at least one row is ticked, a blue bulk bar appears above the table with the number of selected documents and the bulk actions.
Selecting the whole page Tick the checkbox in the table header — every document visible on the current page is selected at once.
ZIP download Click the Download (ZIP) button in the bulk bar. The system packs the files of all selected documents into a ZIP and offers it for download. Inside the package the files are arranged into folders by filing book, and their names contain the filing number.

Adding a tag to several documents

Click the Add tag button in the bulk bar. A window opens showing at the top how many documents are affected. Type the tag name or names into the input field (several separated by commas, for example quarterly, consolidated), or click one of the quick-select tags below (urgent, renewal, for approval, monthly, weekly, HR, receivables, shipping). Click Add. The tags go onto every selected document, without duplication.

Clearing the selection

Click the Clear selection link on the right of the bulk bar — every tick disappears and the bulk bar closes.

The selection survives filtering

If you select rows and then change the filter, the selection is kept even if the filter hides rows. The bulk bar then indicates, for example, that 5 are selected but 3 are not visible under the current filter. They reappear once you reset it.

Saved views

If you often use the same filters, save them as a view and reload them any time with one click.

Item What it means
Built-in views

Click the Views button in the toolbar — a dropdown opens with the predefined views:

  • All documents (default)

  • My uploads

  • Awaiting approval

  • Expiring within 30 days

  • Expired
Using a view

Click one of the items in the dropdown — the view's filters load, the list refreshes, and the chips appear in the active filter bar. The label of the Views button changes too, so you can see which view is active.
Saving a new view

  • Set the filters exactly as you want to use them (combining search, date and detailed filters)

  • Open the Views dropdown

  • Click the + Save new link at the bottom

  • Give the view a descriptive name (for example Q2 focus, Tax authority letters)

  • Check the filter summary shown in the window

  • Click Save — the view is added to the dropdown
Editing a saved view

Load the view from the dropdown, change the filters, then save it under the same name. The system overwrites the old one.
Deleting a saved view

Hover over the view in the dropdown — a bin icon appears on the right. Click it and confirm the deletion.

Export

The filtered list can be exported in three formats. Click the Export dropdown in the toolbar and choose a format.

Item What it means
Excel export Choose the Excel (.xlsx) option. Every column in the downloaded file is formatted, and it opens as a filterable table in Excel or Google Sheets. Ideal if you want to process the data further.
CSV export Choose the CSV (.csv) option. You get a comma-separated text file you can import into other systems (an accounting package, say). Accented characters are saved in UTF-8.
PDF export Choose the PDF (.pdf) option. You get a printable A4 landscape PDF. The header shows the company logo, the name of the list, the date and the active filters. Ideal when you have to hand in or archive a printed report.
What the export contains The export always contains the currently visible, filtered list — not the whole database. If you want to export everything, first remove all filters with the All documents option in the Views dropdown, or the Clear all link in the active filter bar.

Paging and display

The pager bar below the table lets you navigate long lists.

Item What it means
Rows per page Click the dropdown on the left (10 / 25 / 50 / 100) and choose how many rows appear on one page. 10 is the fastest; 100 is useful when you want a broader overview.
Pager buttons To the right of the dropdown are the < arrow (previous page), the page numbers, and the > arrow (next page). Click a page number to jump. The current page is highlighted in blue.
Displayed range To the right of the pager you read the information text, for example Showing 1–10 of 242. So you always see how much of the whole you are looking at.

If something is wrong

What you see What to do
A document you know exists does not appear Check three things in this order. Click Clear all in the active filter bar so nothing is filtered. Switch off any active tile by clicking it again. If it still does not appear, open the Filters panel and tick Archived under Status — someone may have archived it. If that does not help either, ask your system administrator to check your permissions; you may not be entitled to see it (another department's HR document, for instance).
The search finds nothing although the document certainly exists First check the date range — the search only looks inside the current date filter. If the range is this year and you are looking for an older document, change the date (Filing date → Last year preset, or clear it). Try a shorter keyword — contr instead of contract. Also look at the small number bubble next to the Filters button: if, say, 3 filters are active, they may together be narrowing the results too far.
Loading is slow Reduce the rows per page from 100 to 25 or 10 in the dropdown on the left of the pager. Narrow the date range to a shorter period (Last 30 days instead of This year). Close your other browser tabs, especially memory-hungry ones. If it is still slow after all this, contact your system administrator.
I selected many rows but the bulk buttons do not appear Check whether the blue bulk bar really appeared above the table. If not, scroll back to the top of the list — that is where it appears. If you changed the filter after selecting, the selected rows may not be visible under the new filter; the bar is still shown, and the counter indicates the hidden selections.
I cannot change a document's filing number It cannot be done. The filing number is fixed permanently so that the sequential numbering stays intact. If a number was issued by mistake, open the document with the pencil icon and click Archive on the detailed page. Then file it again with the correct data — it receives a new filing number.
The downloaded ZIP does not contain every file I expected The ZIP only downloads the selected documents from the currently filtered list. Check that the selection really covered everything you wanted. If there are several pages of documents, you have to select page by page (the header checkbox only ticks the current page), or set the page size to 100 so they fit on one page. If a file is 0 bytes or damaged in the ZIP, contact your system administrator — the original file may be missing on the server.
