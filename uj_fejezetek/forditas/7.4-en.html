A filing record is always one file plus the data that belongs to it: document type, filing book, serial number, partner and owner. This chapter walks you through recording a filing.

You reach the function on the Document filing → Document list screen: at the top of the page, next to the title, the blue + Create button opens it.

Starting the filing

Open Document filing → Document list and, at the top of the page next to the Document list title, click the blue + Create button. The File a new document panel slides in from the right and the list behind it dims.

On the left of the panel you work through three numbered sections: 1. Filing type, 2. Basic data and 3. Relations. Meanwhile the Filing summary panel on the right continuously shows what the serial number, the filing number, the filing book and the status will be. At the bottom, the green Create filing button completes the work.

If you cannot see the + Create button, you do not have filing permission — ask your system administrator.

Filing type

At the top of the panel there are two large selection cards. Choose whether you are filing a general or an expiring document. The choice determines whether the expiry date fields appear.

General document

Click the General document card when the document has no validity deadline. This covers incoming and outgoing invoices, bank statements, e-mail attachments, project documents, logistics work sheets, HR paperwork and templates. This is the default choice when the panel opens.

Expiring document

Click the Expiring document card when the document has a validity deadline and you want a reminder before it. This covers permits, certificates, contracts, licences, lease agreements, insurance policies, qualification certificates, and environmental and fire-safety permits. After you click it, the expiry date and reminder fields appear on the form.

Basic data

In the Basic data section below the filing type, enter the document's essential details. Fields marked with an asterisk (*) are mandatory.

Document type

Open the Document type dropdown and select the appropriate type: Payment reminder, Incoming invoice, Outgoing invoice, Bank statement, E-mail attachment, Contract, Permit, Certificate, Logistics work sheet, Asset handover, Word template, Voucher template, Legal document, General. Based on the selected type the system automatically sets the matching filing book.

Filing book

After you choose the document type, the system also sets the Filing book field automatically. If you want to use a different filing book, open the dropdown and pick from the 12 books:

  • EA — E-mail attachments

  • SZ — Contracts

  • EN — Permits, certificates

  • FF — Payment reminders

  • BK — Bank statements

  • LM — Logistics work sheets

  • ES — Asset handover (HR)

  • WS — Word templates (HR)

  • BS — Voucher templates

  • MG — Management documents

  • JG — Legal documents

  • ALT — General filing book

Serial number

The Serial number field is generated automatically from the current counter of the selected filing book. Format: BOOK/YEAR/SIX-DIGIT (for example EA/2026/000243). The field cannot be edited. If you switch filing book, the serial number is refreshed immediately to the next free number in the new book.

Document name

In the Document name field, enter how the document should appear in the list. Make it descriptive — do not simply copy the file name. Good examples: May 2026 service report — Ganz Machines Ltd., Electricity bill May 2026 — 15 Petőfi Street, Lease amendment no. 3 — Virág Ltd. 2026. Bad example: invoice_0015.pdf.

Description

Optional field. Add a fuller explanation or context if needed — for example Third amendment of the April machine maintenance contract, agreed with the new partner. The search looks in this field too, and it also appears in the Quick view side panel.

Expiry date and reminder

This section only appears if you selected the Expiring document type in the first step. Here you give the document's validity deadline and when you want to be reminded before it expires.

Expiry date

In the Expiry date field, enter the last day of validity in the Hungarian format: YYYY. MM. DD. (for example 2026. 12. 31.). The space after the dots is optional — the system also accepts the 2026.12.31 format. The help text below the field always shows the example.

Reminder

Set how many days before expiry you want an e-mail notification. The default is 30 days. Either type another value between 0 and 365, or click one of the quick-select buttons: 5, 15, 30, 60, 90. The selected preset is highlighted in blue.

Which lead time to choose

For short-term items 5–15 days is enough (for example a parking permit). For standard contracts 30 days is appropriate. For more significant contracts that need negotiation, 60–90 days is recommended (leases, large supplier framework agreements). For permits that require official administration, 90–180 days is the safe choice (environmental, fire safety, construction).

Related data

In the Relations section you can optionally add further context. None of these fields is mandatory, but they improve retrievability and make the document visible in the related modules as well.

Partner

Start typing the partner's name or tax number in the Partner field — an autocomplete list appears. Click the right partner. Partners come from the CRM module. A document can be linked to one main partner only. If you do not want to give a partner, leave it empty or choose the — None — option.

Project

Open the Project dropdown and choose from the list of open projects. This is useful when the document belongs to a specific project — it then also appears on the project's Documents tab.

Cost centre

Open the Cost centre dropdown and choose from the list. This is useful for financial breakdown — cost-centre based reports take the document into account as well.

Direction

Click the matching direction pill (this is a mandatory field):

  • Incoming — arrived from an external source, for example a supplier or an authority

  • Outgoing — we sent it out, for example to a customer or an authority

  • Internal — within the company, for example a document between two departments

The selected pill turns blue.

Owner

Open the Owner dropdown and choose a colleague. By default you are the owner, but you can assign anyone. For the assigned colleague the document appears automatically in the My tasks list under the My work menu.

Uploading the file

Exactly one file belongs to one filing record. If you have several files for the same document, pack them into a ZIP, or file them separately with linked tags.

How to upload a file

There are two ways. Drag the file onto the marked upload area in the panel (drag and drop), or click the Select file button of the upload area and pick the file from your computer. The name and size of the selected file appear immediately below the area.

Permitted file types

  • Document: PDF, DOC, DOCX, ODT

  • Spreadsheet: XLS, XLSX, ODS

  • Image: PNG, JPG, JPEG

  • E-mail: EML, MSG

  • Archive: ZIP

File size

The maximum size of one file is 50 MB. If yours is larger (for example a PDF scanned at high resolution), compress it, or ask your system administrator to raise the limit.

Replacing the file before upload

If you picked the wrong file, click the × icon next to the displayed file name, then choose a new file.

Saving

When you have filled in every mandatory field, click the green Create filing button at the bottom. The button sits in the lower right corner of the panel.

What happens while saving

The system validates the fields. If a mandatory field is missing, the button does not start the save, the border of the faulty field turns red, and a warning text appears below it. Fix the error, then click save again. On success the system generates a unique filing number, uploads and stores the file in the appropriate directory, assigns it to the selected owner, shows a green toast notification (for example Filing created, EA/2026/000244), closes the panel, and the main list refreshes — the new document appears at the top (if the list is sorted by date).

Cancelling the save

If you decide not to save after all, click the × icon in the top right corner of the panel, or press Esc. The system warns you that the data you entered will be lost — confirm the cancellation.

What happens after saving

After a successful save the document is immediately searchable in the Document list. If you set an expiring type, the system also sets up the expiry reminder.

The document appears in the list

In the Document list the new document appears at the top (if the list is sorted by date). Click the pencil icon on it to open it, or the eye icon for a quick overview.

Expiry reminder

If you set an expiring type and a reminder, the owner receives an automatic e-mail notification the given number of days before expiry. The document then also moves into the yellow Expiring soon tile and appears in the owner's My tasks list.

Approval process

If an approval rule is attached to the filing book, the document's status automatically becomes In progress. The first approver, or all approvers (depending on the rule), receive an e-mail and an in-app notification. Until approval the document is also shown on the green Awaiting approval tile.

Correcting a document afterwards

If after saving you realise something went in incorrectly, almost every piece of data can be changed later — except the filing number.

Changing metadata

Open the document from the list with the pencil (Open) icon. On the detailed editor page you can change the document's name, description, partner, project, cost centre, direction, tags, expiry date, reminder days and owner. Save your changes with the Save button.

Replacing the file

On the detailed page click the Replace file option. Choose a new file. After the new file is uploaded the old version is not lost — it goes into the version history and can be reviewed at any time.

The filing number cannot be changed

The filing number cannot be altered in any way. If a serial number was issued by mistake, archive the incorrect document with the Archive button on the detailed page, then file it again with the correct data — it will receive a new filing number.

If something is wrong

The + Create button does not appear

You do not have filing permission for this module. Ask your system administrator to grant it. Reloading the page does not help — the permission is set under System → Users.
