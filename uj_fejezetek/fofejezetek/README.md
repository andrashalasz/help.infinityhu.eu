# Főfejezet-leírások

A súgó szerkezete szerint **a főfejezet összefoglal, az alfejezetek a
menüpontok**. Nyolc főfejezetnek nem volt saját összefoglaló lapja – az
admin „nincs leírás” jelzéssel mutatta őket, a nyilvános oldalon pedig a
kártyájuk egyből az első alfejezetre ugrott.

Ez a nyolc szöveg **2026-10-06-án kikerült az élesre**, a fájlok itt csak
hivatkozásul maradnak.

|---|---|---|
| `1-elso-lepesek.html` | 1 Első lépések | 334 |
| `3-a-rendszer-hasznalata.html` | 3 A rendszer használata | 335 |

leírása, azokhoz nem nyúltunk.
