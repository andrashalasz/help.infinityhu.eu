4.3.1Kassentransaktionen

Die Erfassung eingehender und ausgehender Kassentransaktionen funktioniert ähnlich wie die Erfassung von Bankvorgängen.

Hat der Partner offene Forderungen, werden diese unten ebenfalls aufgelistet und können mit der Bareinzahlung verknüpft werden. Der Eingang kann auch ohne Verknüpfung mit einer Rechnung erfasst werden.

Geben Sie zuerst die Kasse an, anschließend Datum, Währung, Betrag, Bemerkung und den einzahlenden Partner. Mit Abschließen wird der Vorgang endgültig gebucht.

Achtung

Eine Bareinzahlung ist nur in einer offenen Kassenperiode möglich.

Nach dem Abschluss können Sie den Kassenbeleg drucken, den das System automatisch erzeugt. Das System kann auch einen Kassenbon ausstellen.

Im Kassenmenü besteht außerdem die Möglichkeit, einen Kassenbericht zu erstellen (1), Kassenperioden anzulegen (2) und den Kassenabschluss durchzuführen (3).

4.3.2Kassenperioden

Dieser Menüpunkt zeigt alle vom Unternehmen eröffneten Kassen, die zugehörigen Perioden und deren aktuellen Saldo.

Zur besseren Nachvollziehbarkeit ist es sinnvoll, innerhalb der Kassen Kassenperioden anzulegen. Pro Kasse kann nur eine Periode offen sein. Bevor Sie eine neue öffnen, muss die vorherige geschlossen werden.

Für die Eröffnung einer Kassenperiode erforderliche Daten:

  • Auswahl der Kasse: aus der Liste der Kassen

  • Eröffnungsdatum: das System schlägt das aktuelle Datum vor (änderbar)

Mit der Schaltfläche Abschluss schließen Sie die Periode. In einer geschlossenen Periode können keine Transaktionen erfasst oder geändert werden. Eine geschlossene Periode kann wieder geöffnet werden, sofern die offene Periode vorher geschlossen wurde.
