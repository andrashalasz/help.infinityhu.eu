10.11 UrlaubsverwaltungVolle Seite

Dashboard → Meine HR-Daten

Das Modul Urlaubsverwaltung dient dem Einreichen, Genehmigen und Erfassen von Urlaubs-, Krankheits- und sonstigen Abwesenheitsanträgen.

10.11.1Urlaubsantrag einreichen

  1. Dashboard – Meine HR-Daten – Tätigkeiten

  2. Wählen Sie die Abwesenheitsart (Urlaub, Krankheit, unbezahlt usw.).

  3. Geben Sie Beginn- und Enddatum an.

  4. Schreiben Sie bei Bedarf eine Bemerkung.

  5. Absenden — der Antrag wartet auf die Genehmigung der Führungskraft.

Feld Typ Pflicht? Erläuterung / Tipps
Abwesenheitsart Enum Ja Urlaub / Krankheit / unbezahlt / Sonstiges.
Beginndatum Datum Ja Der erste Abwesenheitstag.
Enddatum Datum Ja Der letzte Abwesenheitstag.
Bemerkung Text Nein Interne Bemerkung; die Führungskraft sieht sie ebenfalls.
Anhang Datei Bedingt Bei Krankheit kann eine ärztliche Bescheinigung angehängt werden.

10.11.2Urlaub genehmigen (Führungskraft)

Die Führungskraft sieht die eingehenden Anträge in der Liste Urlaubsverwaltung → Wartet auf Genehmigung. Sie kann sie genehmigen, (mit Begründung) ablehnen oder zur Änderung zurücksenden.
