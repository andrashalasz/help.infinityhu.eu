4.2 BankVolle Seite

Im Menüpunkt Bank können Sie eingehende und ausgehende Überweisungen, Kartenzahlungen und -auszahlungen sowie Nachnahmeforderungen erfassen.

Beim Erfassen haben Sie zwei Möglichkeiten: Sie verknüpfen die Transaktion mit einer Rechnung (wählen Sie dann die Rechnung aus der unteren Liste) oder nicht. Ein Beispiel für Letzteres ist die Erfassung von Bankzinsen.

Geben Sie zuerst die Bank an, anschließend Datum, Währung, Betrag, Bemerkung und den einzahlenden Partner. Mit der Schaltfläche Einkopieren übernehmen Sie die Rechnungsnummern der ausgewählten Rechnungen in das Feld Name/Rechtsgrund. Mit Abschließen wird die Transaktion endgültig gebucht.

Achtung

Eine Bankeinzahlung ist nur in einer offenen Bankperiode möglich. Ob die Periode offen ist, können Sie im Menüpunkt Bankauszüge prüfen.

Weicht die Währung der Rechnung von der Währung der Bank ab, wählen Sie im Auswahlfeld Währungsumrechnung die gewünschte Währung, den Kurstyp und den Kurs aus. Weicht der von der Bank verwendete Kurs vom durch das System abgerufenen ab, können Sie ihn auch manuell eingeben.

4.2.1Bankauszüge

Die Entwicklung der Bewegungen auf den Bankkonten lässt sich in diesem Menü nachvollziehen. Es sammelt die zum jeweiligen Bankkonto gehörenden Transaktionen und zeigt den aktuellen Saldo.

Die Bankauszüge müssen auch in Infinity erfasst werden, damit beim Auflisten der Bankkonten der Saldo unmittelbar sichtbar ist und Sie Ihren Partnern eine aktuelle Forderungsliste geben können.

Die Erfassung ist auf zwei Oberflächen möglich:

  • Durch Ausgleich von Kunden- und Lieferantenrechnungen (Rechnungsliste → Rechnung auswählen → Überweisung)

  • Durch Erfassung einer neuen eingehenden/ausgehenden Überweisung

Die Listenverwaltung Bankauszüge enthält die Liste der zum jeweiligen Bankkonto gehörenden Auszüge. Einen neuen Bankauszug erstellen Sie mit der Aktion Bankauszug bearbeiten.

Pro Bankkonto kann nur eine Periode offen sein. Bevor Sie eine neue öffnen, muss die vorherige geschlossen werden.

Für die Eröffnung eines Bankauszugs erforderliche Daten:

  • Auswahl des Bankkontos: aus der Liste der Belege vom Typ Bank

  • Eröffnungsdatum: das System schlägt das aktuelle Datum vor (änderbar)

Bankauszug ansehen

Öffnen Sie den Bankauszug aus der Listenverwaltung Bankauszüge, um die zugehörigen Transaktionen anzusehen.

Mit der Schaltfläche Abschluss schließen Sie die Periode. In einer geschlossenen Periode können keine Transaktionen erfasst oder geändert werden. Eine geschlossene Periode kann wieder geöffnet werden, sofern die offene Periode vorher geschlossen wurde.

4.2.2Umbuchung

In diesem Menü können Sie Geld zwischen den im System vorhandenen Kassen und Bankkonten bewegen — auch zwischen verschiedenen Währungen, durch Angabe eines Kurses.

4.2.3Spezielle Banktransaktionen

Sie können spezielle Banktransaktionen anlegen, mit denen auch künftige Überweisungen wie Steuern oder andere Zahlungsbewegungen ohne Beleg erfasst werden können.

4.2.4Ausgleich von Überzahlungen

Das System bietet auch die Möglichkeit, Überzahlungen in vereinfachter Form auszugleichen.
