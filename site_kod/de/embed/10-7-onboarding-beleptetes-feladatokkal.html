10.7 Onboarding – mit AufgabenlistenVolle Seite

Ziel des Onboardings ist, dass der neue Mitarbeiter vom ersten Tag an arbeitsfähig ist. Das System erzeugt anhand einer Vorlage Aufgaben und verfolgt deren Erfüllung (HR/IT/Führungskraft/Mitarbeiter).

10.7.1Start des Onboardings nach der Einstellung

Bei der endgültigen Einstellung — wenn wir den Kandidaten in einen Mitarbeiter umgewandelt haben — erstellt das System automatisch eine Onboarding-Instanz und erzeugt anhand der gewählten Vorlage Aufgaben. Die Frist der Aufgaben wird relativ zum Eintrittsdatum berechnet (z. B. −5 Tage).

10.7.2Onboarding-Listenansicht

In der Listenansicht sehen Sie alle laufenden Onboardings mit Fortschrittsangabe in Prozent. Sie können nach Eintrittsdatum, Abteilung, Führungskraft und Status filtern. Die rote Anzeige bedeutet eine Verzögerung (Frist abgelaufen, Aufgabe nicht erledigt).

10.7.3Onboarding-Detailansicht – Aufgaben verwalten

  1. Öffnen Sie den Onboarding-Datensatz aus der Liste.

  2. Sehen Sie sich die nächste Phase an (z. B. Day 1).

  3. Klicken Sie auf eine Aufgabe: setzen Sie sie auf IN_PROGRESS oder DONE.

  4. Gibt es eine Blockade, setzen Sie sie auf BLOCKED und schreiben Sie eine Bemerkung.

  5. Bei einer verspäteten Aufgabe informieren Sie den Verantwortlichen (das System kann ebenfalls eine Erinnerung senden).

10.7.4Probezeit und Bewertung

Befindet sich der Mitarbeiter in der Probezeit, erzeugt das System gegen Ende der Probezeit automatisch eine Bewertungsaufgabe für die Führungskraft. Diese sollte rechtzeitig abgeschlossen werden, da das HR-Dashboard eine gesonderte Warnung zur nahenden Frist ausgibt.
