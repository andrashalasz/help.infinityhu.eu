Card payment terminals

Updated 2026.08.26 · v2026.08.26

Creating a new card reader is required for card payments. Available at: Finance → Settings → Card payment terminals.

  • The type must always be “physical”

  • The site where the cash desk operates can be selected from a list

  • Serial number pattern and commission percentage: fixed values, as given in the example

  • Claimable partner: the bank to or from which the card transactions arrive

  • Its status must always be “enabled”

The values entered can be finalised with the Save button.

5.2.1Current account list

Here you record the building blocks of the analytical documents created by business events. Among others, you define the documents for invoice-based sales, supplier invoice issuing and financial transactions. Setting up the documents is an admin task, usually done before the system goes live.

5.2.2Accepted vouchers

Used primarily in retail sales to manage accepted vouchers. Both third-party and own-issued vouchers can be recorded, and the turnover can then be queried by voucher type.

5.2.3Invoice and receipt blocks

For documenting outgoing invoices you can create a serial number and an invoice layout. A serial number can also be assigned to receipts for easier tracking.

A separate serial number and layout can be assigned to the proforma invoice, the advance invoice and the advance payment request as well. The type of the invoice block can be: customer/supplier invoice, customer/supplier advance payment request, receipt, interest letter, proforma invoice, partial invoice, final invoice.

For the origin: with internal, you define the structure of the serial number (in the serial number pattern field); with external, the program generates it automatically. Under site, specify at which site you want to use it.

5.2.4Cost categories

The cost category is a mandatory element when recording customer and supplier invoices. It is one of the important building blocks of the automatic posting rules: when a supplier invoice is recorded, the system can post it automatically based on the cost category.

5.2.5Cash discount (sconto)

To apply a cash discount, you first have to create the discount rules and then assign them to a partner.

A cash discount can be accounted for on both customer and supplier invoices, but only for a partner whose record has previously been assigned a discount rule.

First specify the reference date — the discount deadlines are calculated from this. After entering the percentage and the number of days, the discount can be assigned to a job number. Several rules can be defined for one partner; if you select more than one, the default has to be specified.

5.2.6Payment methods

Here you can define the payment methods used in the system.

5.2.7Cost centres

The system allows cost centres to be recorded, which break the general ledger accounts down into further dimensions and enable deeper cost analysis.
