13.2.1Events

Event type

Used to group events. By default: quotation, order, invoicing, service. A new type can be, for example, meeting, customer service or phone call. Data to be entered: name (mandatory), status (active/inactive), default duration.

Event status

Here you define the possible statuses of the individual events. By default: New (not closing, active) and Closed (closing, active). Data to be entered for a new event status:

  • Name: for example done, in progress, unsuccessful (mandatory)

  • Closing status marker: if ticked, the event is closed and requires no further attention

  • Opening status marker: can be used for events integrated into a workflow

  • Colour: the event appears in this colour when listed

  • Status: active or inactive (mandatory)

13.2.2Priorities

When a CRM event is created, the priority can be indicated. The default priority is applied automatically to every new event.

13.2.3Rooms

Rooms can be recorded for organising an event.

13.2.4Enquiry types

The place for recording the enquiry types selectable on the record.

13.2.5Reason for failure

Recording the reasons selectable when a CRM process is closed unsuccessfully.

13.2.6Notifications

The notification automatically creates an entry on the record of the CRM project where it is enabled. For example, if you want to send an automatic reminder 2 days after an event has been recorded, click the Create notification button:

  • Category: from the list predefined on the Notification categories subpage

  • Name and text: freely definable, they determine the content of the notification

  • Notification time: how many days after the recording of the event it should appear

After saving, the notification can be assigned to one or more event types. When the given event type is recorded, the notification appears automatically once the specified time has elapsed.

13.2.7Templates

Used for projects of the Project management type. They have to be sorted into template categories and contain a free-text field. On the records they display checklist-type information — for example in a simplified construction template the steps follow each other in logical order.

13.2.8Questionnaires

The questionnaire function serves faster customer feedback. The questionnaire can be sent to the customers concerned from the CRM record at the press of a button. When creating a new questionnaire, give it a unique name and a type, and set whether completing it is mandatory.

The answer types:

  • Free text: it can be answered in the respondent's own words

  • Multiple choice: several options can be selected

  • Drop-down: one option can be chosen from a predefined list

  • Single choice: only one option can be marked

Sending the questionnaire: on the home page, under the Projects tab, open the given project, click the partner's record, then click the button in the top right corner, fill in the e-mail editor screen and send it with the questionnaire.

The completed questionnaire can be viewed by clicking the contact under the given project.

13.2.9Contact settings

The parameter settings responsible for the appearance of the Lead and Contacts forms. With the parameters configurable here, the forms can be customised and supplementary data displayed.

13.2.10Form editor

Editing the Lead and Contact entry forms. Any fields can be added to the forms and they can be categorised.

13.2.11Contact groups

CRM contacts can be sorted into groups. The group can be selected on the contact form.

13.2.12Contact type

Recording the type names selectable when entering a lead or contact. Contact priorities, the Source (where the given contact came from, for example an exhibition or an advertisement) and the Tags (predefined markers supporting searching and reporting) can be recorded in the same way.

13.2.13Lead/Opportunity settings

Leads can be categorised (for example cold lead, hot lead, marketing qualified lead, sales qualified lead) — this way the salespeople know which prospect is at which level. Opportunities mark the more advanced stages, where concrete negotiations are under way; the progress of the sales pipeline and the steps needed for closing are transparent.
