10.9 Documents and recordsFull page

Menu: HR → Documents and records

The Documents and records module serves to store and manage every document related to the employees (contracts, declarations, certificates).

10.9.1Uploading a document

  1. Menu: HR → Documents and records → New document, or from the employee's profile on the Documents tab.

  2. Select the employee.

  3. Enter the type of the document and its validity date (if relevant).

  4. Upload the file (PDF/DOCX recommended).

  5. Save.

Field Type Mandatory? Explanation / tips
Document type Enum Yes For example employment contract, confidentiality declaration, certificate.
Employee User Yes Which employee it belongs to.
Start of validity Date No Relevant for contracts.
End of validity Date No For the expiry warning.
File File upload Yes PDF/DOCX format recommended.
Comment Text No Internal comment.
