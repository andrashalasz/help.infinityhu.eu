7.1 SettingsFull page

The approval process is closely related to filing. Activities that may require approval:

  • Payment batch — the authorised user is notified in the information bar about the invoices to be certified, which can be opened, approved or rejected directly from there

  • Accountability of an incoming invoice — after the payment approval, the accounting and VAT dates appear; once these are filled in, the invoice can be handed over for accounting

  • Approval of quotations — every quotation, or only quotations above a certain value limit, can be sent for approval

  • Approval of orders — likewise for all orders or only those above the value limit

  • Approval of an outgoing invoice — after closing, but before the document is produced

  • Approval of a cash payment

7.1.1Document types

By creating filing types you can set up document groups that match your business processes. Data to be entered:

  • Code: short identifier, 3 characters, mandatory

  • Name: free text, mandatory

  • Serial number pattern: can be given per filing type (not mandatory)

  • Site: if given, filing is only possible at that site (not mandatory)

  • Type: invoice or document type (mandatory)

  • Expiring document: if yes, entering the expiry date is mandatory when uploading the document

  • Directory: the directory the filed documents are placed in

  • Status: active or inactive (mandatory)

7.1.2Expiring document type

Documents with an expiry date (for example certificates, permits, attestations) can be recorded in the system. When creating the document type, it has to be specified whether documents of that type expire.

Automatic notification system:

90 days before First notification to the person responsible
60 days before Reminder to the person responsible + notification to the supervisor
30 days before Urgent warning to both parties
14 days before Critical warning
On the day of expiry Expired status + immediate notification
Weekly after expiry Recurring reminder until renewal

Notification channels: e-mail notification, dashboard widget.

  • Dashboard of the person responsible: it arrives in the My tasks widget and can be found in the My documents list, sorted by expiry date

  • Supervisor dashboard: a consolidated overview of the documents of the organisational unit, with the list of expiring documents by priority

7.1.3Approval protocol

Used to control the approval processes. Fields to be entered:

  • Code: 3 characters, mandatory

  • Name: free text, mandatory

  • Minimum value: below which approval is not required (numeric, not mandatory)

  • Currency: the currency of the amount (default: HUF)

  • Site: if given, it is only valid at that site (not mandatory)

  • Approver: a user selectable from the partner list (mandatory)

  • + Approver: further approvers can be added (unlimited number, not mandatory)

  • Score: a score has to be given for every approver — the document can only be considered approved once 10 approval points have been collected (values between 1 and 10)

  • Status: active or inactive (mandatory)

7.1.4Documents awaiting approval – information bar

The approving user finds the documents awaiting approval in their information bar. If several users have to approve and the current one has already approved, their item turns green. To withdraw the approval, click the item again and reject it.

From the list you can reach the document to be approved with a single click. The list contains all the necessary information, including the number of approval points received so far. In the approval window you can send a message to the issuer of the document or to the other approver. With the Approve field you approve the document (as many points are recorded as the approval protocol prescribes). In the case of rejection, minus points are assigned.

Caution

If a document under approval is modified, all approval points are deleted and the approval process starts again.

7.1.5Filing register

When creating the digital filing register, enter the name of the register and the prefix and suffix of its serial number. In the register list, add the user who has permission to use it. The system automatically creates a filing register in which it places the documents.

The filing process:

  1. The user uploads the document into the Filing widget under the Document upload tab on the home page.

  1. The documents are placed in a list, which the authorised user sees on the home page under the My tasks tab.

  1. The user categorises the documents one by one, marks the partner or employee (not mandatory), places the document in the filing register, then presses the filing button.

  1. The document receives a filing number and a time stamp; the name of the filing user is also stored.

  1. The user assigns the document to a division or to one or more users.

  1. The designated user processes the document by clicking the process button.

Types of the filed document:

  • Invoice: clicking the filing button opens the invoice entry page, the document is attached automatically and the partner is already selected

  • Employee document: the employee document screen opens, where the division and the employees have to be selected

  • General document: the basic upload screen appears, where the document is archived for the given partner
