Clicking the column headers sorts the displayed data alphabetically.

You can search by typing into the search fields below the column headers. Where a small downward arrow appears at the edge of a search field, you can filter from a drop-down list.

The texts displayed in the table are live links — clicking one navigates to the given document. The first column holds the buttons for quick view, edit, sending the document by e-mail and immediate settlement:

On pages with a table view, the data can be exported to Excel. There are two ways:

  • Select the displayed data with the mouse, copy it with Ctrl+C / Command+C, and paste it into Excel.

  • Click the button placed above the table list to export the data to Excel.
