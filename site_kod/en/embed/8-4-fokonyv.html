8.4 General ledgerFull page

The general ledger module collects and organises the data from the other modules. Whether a given document reaches the general ledger depends on the posting configured during parameterisation.

The type of posting can be twofold:

  • Automatic posting: based on the automatic posting rules, the given document reaches the general ledger automatically

  • Manual posting: the user selects manually from the postable general ledger accounts

The only transaction created exclusively in the general ledger module is the mixed type posting, which can be applied to every item not related to any other module (for example wages and contributions, taxes, openings, closings, transfers). The collection is made on general ledger accounts, which can be extended with a further dimension by using cost centres and job numbers.

8.4.1Posting details

It is not necessary to place every analytical document under automatic posting. In the Posting data menu you can simply set which ones you define automatic posting for.

8.4.2Project numbers / job numbers

The system also allows a project or job number to be recorded, which can be linked to a partner and/or a warehouse. The system uses this number for posting as well. A project number, a name, the partner and/or the warehouse, and the status (active/inactive) have to be given.
