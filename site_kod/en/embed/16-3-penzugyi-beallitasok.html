16.3.1Invoice-issuing company

At first use, the invoice-issuing company has to be specified. If partner data are already available, it can be selected from the list, or it can be added as new.

⚠ Caution

After the first sign-in, check whether your user is assigned to the invoice-issuing company. If the address of the invoice issuer changes, it will only appear on invoices issued after the change.

In the inventory settings, add the warehouses and stock types used.

16.3.2Currency master data

It contains every currency in the world — the default and the active currencies can be selected from these. The daily exchange rates can also be found here, but for automatic rate download the interface data have to be added at the rate types.

16.3.3VAT master data

It contains the VAT rates, the collective codes and the VAT code types. The VAT rates can be modified freely; the VAT codes are updated continuously based on the data published by NAV.

16.3.4Interest rate and collection fee

The place for entering the interest required for payment reminders and notices. Based on the EU guidance, a one-off collection fee of up to EUR 40 can also be charged. The values and percentages can be entered with the + button.

16.3.5Serial number pattern

The format of the serial numbers of the documents used in the system can be specified. The pattern has to be built next to the given parameter with the help of the blocks found on the page.

16.3.6Bank account query

Used to connect the company's bank accounts. Infinity displays the transactions of the connected bank accounts and can easily link them with the customer and supplier invoices, reducing administration. Click the Add new bank sync button, select the country and the bank, then authorise Infinity's access on the bank's interface.

ℹ Note

The connection created here is encrypted — no third party can access the data.
