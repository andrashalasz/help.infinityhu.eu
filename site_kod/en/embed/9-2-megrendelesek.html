9.2 Customer ordersFull page

An order can be created in two ways: directly with the New order menu (without a quotation), or from a quotation by clicking the Order button. When created from a quotation, it is filled in with the quotation's data, but every field remains editable. If the customer accepts the quotation, the system automatically converts it into an order, which appears among the orders with open status.

ℹ If the customer accepted the quotation and the system created the order automatically, pressing the Reserve button lets you check whether every item is in stock.

Saving the order means reserving from stock. If a product on the order is not in stock, the order cannot be closed and a purchase order has to be started for it by pressing the Start order button.

The possible statuses of orders:

Open Saved order, does not have a serial number yet, editable
Reserved Already reserves stock, awaiting fulfilment
Deleted Reversed order, the stock reservation is released
Fulfilled Delivered and invoiced order

In the header of the order — directly below the title — the document chain bar appears. From here, both the source quotation and the related purchase order can be reached with a single click, without having to return to the list view.

⚠ If the order was created automatically from a quotation, the chain appears automatically. If the order was created manually (not from a quotation), the chain only points towards the purchase order.

Pressing the Invoicing button converts the order into a customer invoice with a single click. If several orders have been fulfilled for one partner, the bulk sales button on the order list invoices all of them at once.
