10.5 Positions – opening, managing, closingFull page

Menu: HR → Positions

A position is a concrete vacancy to be filled. Recruitment is always tied to a position, so a candidate can only be recorded against an existing, open position.

10.5.1Creating a position

  1. Menu: HR → Positions → New position

  2. Enter the name of the position and select the job role.

  3. Select the division, the hiring manager and the site.

  4. Set the type of employment, the working mode and the seniority.

  5. Enter the headcount and the planned starting date.

  6. If needed, fill in the compensation and the other fields (salary band, cost centre, project).

  7. Save — the status is Draft by default; to start recruitment, set it to Open.

Field Type Mandatory? Explanation / tips
Position name Text Yes The name of the position; this appears in the lists and in recruitment.
Job role Drop-down Yes The job type of the position. Loaded from the master data under Settings → Job and employment → Job roles.
Division Drop-down No Which division it belongs to. Loaded from the master data under Settings → Organisational structure → Division.
Hiring manager Drop-down Yes The manager responsible for the position. In the manager view, they only see their own positions.
Site Drop-down No Which location it applies to. Loaded from the master data under Settings → Organisational structure → Location.
Headcount Number Yes How many people have to be hired. Once it is filled, the system warns you when a new candidate is added.
Status Drop-down No Default: Draft. Recruitment can only be started with the status Open or Paused.
Employment Drop-down Yes The type of employment (for example full-time, part-time, contractor). Loaded from the master data under Settings → Job and employment → Type of employment.
Working mode Drop-down No Office / hybrid / remote. Loaded from the master data under Settings → Job and employment → Working mode.
Planned starting date Date No When the position should be filled. It helps to prioritise recruitment.
Seniority Drop-down No The level assigned to the job role (for example junior, medior, senior). Loaded from the master data under Settings → Job and employment → Seniority level.
Salary band min / max Number No The planned salary band. Permission-dependent — only HR/Finance can see it.
Currency Drop-down No The currency of the salary band (for example HUF, EUR).
Cost centre Drop-down No Which cost centre the position is charged to. Useful for financial reports.
Project Drop-down No If the position is tied to a project, it can be assigned here.
Position description Long text No The detailed description of the role; it can also be used for an internal or external advertisement.
Requirements Long text No The expected qualifications, experience and skills.
Comment for internal use Long text No Only HR and the manager see it; negotiation points, internal context.

10.5.2Position statuses in practice

Draft: the position is not active yet, recruitment cannot be started.

Open: recruitment is allowed, new candidates can be added.

In progress: the selection is actively under way, the position is not filled yet.

Filled: the headcount is full; adding a new candidate is prohibited or flagged with a warning.

Cancelled: a closed or cancelled position, archive view only.

Tip: if the headcount is full but an extra person is still needed, increase the headcount first and only then record the new hire.
