13.6 CRM process based on projectsFull page

The process starts with the creation of the project. After the project record has been filled in, it appears on the start screen of the creator and the owner.

13.6.1Normal project supporting sales

Click the New record button to create a new record for the project:

After the record has been opened, two columns are visible: on the left the tasks and the history, on the right the data of the record.

Creating a new history entry

Click the Add new history entry button:

Fill in the text part, select the event type, attach a file if required, then click the Successful or Unsuccessful button.

Creating a new task

Click the Add new task button, select the owner, the deadline, the priority and the type, and enter a description:

Changing the data of the record

In the right-hand column you can change the Owner and the Enquiry type, add a comment, and enter the date of the quotation, the expected revenue, the closing date and the reason for failure.

13.6.2Customer service and customer management project

Two modes: a record opened manually, or reports arriving at the e-mail address set on the project.

Manual record:

The reports arriving at the configured e-mail address can be opened by clicking the button:

After opening, the following can be set: channel of the enquiry, task type, owner, partner assignment, priority, status, deadline. It can be attached to another task and a file can be uploaded as well. The system sends an e-mail to the partner concerned when the status changes and when the state of the task changes.
