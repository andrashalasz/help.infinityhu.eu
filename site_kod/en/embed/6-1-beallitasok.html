6.1 SettingsFull page

6.1.1Manufacturers

The master data of the manufacturers used for the recorded products. With the help of manufacturers you can group your items, speed up searching and separate the brands. One manufacturer can be given for each item.

6.1.2Product category list

A tree-structured, hierarchical marker for grouping the products. An unlimited number of product categories can be assigned to an item, so items can be grouped according to several aspects.

The existing structure can be listed under Inventory → Settings → Product category list. New categories can be added and existing ones modified here as well.

6.1.3Stock list

Stock is a category serving to separate the goods stored in the warehouses. You can distinguish own, consignment, externally stored, taken-in-for-service and used stock. When creating a product, the stock type always has to be specified.

6.1.4Warehouse list

Used to create and maintain warehouses — the number of warehouses can be extended without limit. Every warehouse has to be assigned to a site, and it has to be set whether selling from it is permitted and whether it is a returns warehouse. Its status can be Active or Inactive.

6.1.5Price type list

The place for defining the selling price types. For sales the system uses the list price types, for procurement the purchase types. To assign an individual price list to a partner, enter a price type on the partner record (Partners → Partner list → Modify).

Using the price type on a product: Inventory → Product → Product list, the appropriate product → Prices worksheet → Add new.

Margin = net selling price − net purchase price; mark-up = (margin / net purchase price) × 100.

To change a price, either open the existing price type for editing and simply overwrite it, or give the old price an end date and add a new price type (in that case a trace of the price change remains).

6.1.7Estimated delivery deadlines

Delivery deadlines can be recorded here. The user can select these in the modules (for example in the Service module) when arranging delivery.

6.1.8Environmental product fees

Companies that manufacture or distribute products containing packaging materials that decompose slowly are obliged to pay the environmental product fee. In the system the KT, CsK and HKT numbers, the price of the packaging material and the text to be printed on the invoice can be recorded.

Note

The size and weight parameters of the products have to be filled in, because the system calculates from these. When selling, the product fee obligation has to be indicated on the invoice.

6.1.9Shelf number

Products can be recorded against a shelf number, and the shelf number can be assigned to a partner. For this, record your shelf number structure in this menu.
