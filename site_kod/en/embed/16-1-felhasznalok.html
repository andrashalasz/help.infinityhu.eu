16.1.1Users

A screen for maintaining the users of the system. Handling it requires appropriate care.

Mandatory fields when creating a new user:

  • Login name

  • Password (at least 8 characters)

  • Status: an inactive user cannot sign in

  • Role: determines the scope of permissions of the user

Fields that are not mandatory but are required for use:

  • Current issuing partner: required for invoice issuing activity

  • Current site: also important for invoice issuing

  • Partner identifier: useful for tracking user logs and for activity-bound processes

16.1.2Roles

Different permission systems can be assigned to different job functions. The advantages: irrelevant activities can be excluded, and a simpler, cleaner working screen can be created.

⚠ Caution

Before the system is introduced, the range of job functions and the required permissions have to be assessed. Managing roles requires considerable expertise — a careless intervention can cause irreversible damage!

A role can be copied, or modified after opening it. Further permissions can be added to a role by typing in the search window and then selecting from the list that appears. Deletion can be performed on the user maintenance screen.

Smart groups

The permission system of Infinity has two levels: first the basic functions are set in the role matrix, then the detailed permissions within the individual roles. Smart groups are loaded during migration, but they can be refined further in the System → Users → Smart groups menu.

If a new permission is added to a smart group, it changes automatically in every role the smart group is assigned to.

16.1.2.1Steps of usage:

  1. Adding a smart group: System → Users → Smart groups menu

  1. Adding permissions to the smart group: assign the activities that are needed together

  1. Assigning the smart group to a role: the role automatically inherits the permissions of the smart group

This solution significantly simplifies permission management and reduces the possibility of errors.
