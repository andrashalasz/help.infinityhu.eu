10.13 Termination / offboardingFull page

Termination is the controlled closing of the employment relationship. The system does not delete data: it archives the employee, closes the employment relationship and (optionally) starts the IT offboarding tasks.

10.13.1Starting the termination

You start the termination on the employee's record with the “Terminate” button. The button is typically only active for HR_ADMIN.

  1. Open the employee's record.

  2. Click: Terminate.

  3. Fill in the dates (last working day, date of termination).

  4. Select the reason for the termination.

  5. Set whether IT offboarding should start and whether assets have to be returned.

  6. Finalise.

Field Type Mandatory? Explanation / tips
Last working day Date Yes Until when they actually work.
Date of termination Date Yes The end of the employment relationship; end_date in the system.
Reason for termination Enum Yes Resignation / mutual agreement / dismissal / probation unsuccessful / expiry / other.
Comment Long text Conditional Mandatory if the reason is “other” or of a disciplinary nature.
Rehire eligible Yes/no No Whether they can be re-employed later; useful for reports.
IT offboarding Check box No If switched on, IT tasks are generated.
Assets List No Laptop/phone/card; it helps with the handover.
Documents File No Attaching the notice or the agreement.

10.13.2What happens after finalisation?

The system sets the status of the employee to TERMINATED, fills in the end_date field, and the employee is removed from the active list. The employee's data remain available in the Archive (Terminated) list. If IT offboarding is active, the related tasks and integration triggers are started as well.

IMPORTANT! After the termination we do not delete the employee record. This is necessary for the reports and the audit.
