13.3 ProjectsFull page

Three kinds of project can be recorded:

  • Normal project: it enables sales and customer management

  • Customer service project: for handling customer service type tasks

  • Project management project: for general project management

The project record consists of three sections: Basic data, Supplementary data (owner, start, duration, end date, expected project value), Other (priority, room).

To create a new project, enter a name (it does not have to be unique):

Normal project:

If you select a modifiable workflow, the system offers the events assigned to that workflow from a drop-down menu. If you do not fill it in, you can freely choose an event type.

The Type can be normal or customer service. In the case of customer service, the data of the e-mail address receiving the reports has to be entered — the system displays the incoming e-mails in the given CRM project.

The Owner can be selected from the partner list. When the start date is entered, the system checks whether the owner has a booking (sick leave, holiday, another CRM event). If so, a warning message appears and the event cannot be saved.

The expected project value can be compared in the statements with the working time cost spent.
