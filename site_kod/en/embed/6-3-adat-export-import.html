6.3.1Bulk item import from a file

If you want to create a large number of new items at once, there is no need to record them one by one — they can be imported from an Excel table. Available at: Inventory → Data export/import → Import product master data.

Before importing, it is advisable to download the sample file and adapt it. Make sure that there are no formulas in the cells of the file to be imported, no filters on the columns, and no hidden unnecessary data. The sample file also contains a completion guide.

Note

If Infinity finds a matching item between those already imported and those to be imported, it does not import the duplicate and does not overwrite it — it skips it.

6.3.2Stock importer

Used for importing opening stock and for making bulk goods receipt easier.

In the product list, filter the items intended for bulk receipt. In Excel, enter the quantities to be received and the outlet code (if you do not work with outlets, the outlet identifier is the same as the site identifier).

After the import, the statistics show whether every row was imported or whether any item was skipped. The erroneous rows can be exported to Excel, corrected and imported again.

To check the goods receipts, click the Check receipts field.

Important

The imported data are only placed in an intermediate store — they are not added to stock yet. A message appears in the information bar on the home page (with the appropriate permission). Clicking the Import button lets you check and receive the allocated stock.

The Approve button finalises the stock movement. The date of the receipt will be the date of the approval.

Stock can also be distributed to other warehouses and outlets. Goods can only be received by a user assigned to the given site.

Handling discrepancies:

  1. If the physical stock is more than the imported quantity:

    • We only take the ordered quantity into stock and send back the surplus

    • Or we take the larger quantity into stock — in this case the discrepancy appears in the Stock receipt pending items menu. If the supplier sends a new delivery note for the surplus, it has to be entered in the Referenced document field.

  2. If the physical stock is less than the imported quantity:

    • We receive the correct (smaller) quantity — the discrepancy also appears in the Pending items menu

    • If the supplier sends the missing quantity: it can be taken into stock with the Approve button

    • If the supplier does not send it: with the Request credit note button we delete the discrepancy row and can request a credit note from the supplier

6.3.3Importing product images

Images can also be uploaded for recorded items. Available at: Inventory → Data export/import → Import product images.

The program only imports compressed (zip) images in JPG format. The file name has to match the item number. If you upload several images for the same item, put a dot and a sequence number after the item number (for example ITEMNO.1.zip). Select the files and upload them with the Upload button.

The uploaded images appear on the product record and in web sales. An image can be deleted by opening the product and clicking the Images tab.
