5.5.1Payment batch lines

To make the workflow easier, bank batches can be created in Infinity and then imported into the bank's transfer interface.

As a first step, select the bank and the originating account number, then give the batch a name. After saving, the system lists every supplier invoice with closed status that has an outstanding balance.

Invoices can be added to the batch with the + button and removed with the red bin button. For invoices marked for transfer:

  • The amount can be modified if not the entire open balance is transferred

  • The current date is suggested as the value date (can be changed)

  • The partner's default bank account number is suggested (can be changed)

  • The number of the supplier invoice is placed in the comment field (can be extended freely)

A saved bank batch is in Open status — all of its data can be modified until it is closed. From a closed batch, the Generate button produces the file to be imported into the bank. If the bank transfer has been made and the batch has not been changed, the Settle button can also settle the invoices contained in the batch.

5.5.2Importing a bank statement

A bank statement can be imported: the items of the electronic bank statement appear in the system and the transactions do not have to be recorded manually. Click the Create button to perform the import; the sample file can also be downloaded from here.

5.5.3Settlement based on a bank statement

Using the imported bank statement you can reconcile the open invoices in the system with the data of the statement, speeding up the administration. Click the Create button to perform the import.
