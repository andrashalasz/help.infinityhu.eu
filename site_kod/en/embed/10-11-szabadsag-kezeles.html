10.11 Leave managementFull page

Dashboard → My HR data

The Leave management module serves to submit, approve and record requests for leave, sick leave and other absences.

10.11.1Submitting a leave request

  1. Dashboard – My HR data – Activities

  2. Select the absence type (Leave, Sick leave, Unpaid and so on).

  3. Enter the start and end date.

  4. Write a comment (if needed).

  5. Submit — the request waits for the manager's approval.

Field Type Mandatory? Explanation / tips
Absence type Enum Yes Leave / sick leave / unpaid / other.
Start date Date Yes The first day of absence.
End date Date Yes The last day of absence.
Comment Text No Internal comment; the manager sees it too.
Attachment File Conditional A medical certificate can be attached for sick leave.

10.11.2Approving leave (manager)

The manager sees the incoming requests in the Leave management → Awaiting approval list. They can approve, reject (with a reason) or send it back for modification.
