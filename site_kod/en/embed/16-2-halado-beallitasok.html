16.2 Advanced settingsFull page

16.2.1Modules

It contains the active modules of the system with a description.

16.2.2E-mail scheduler

It contains the list of e-mails sent by the system, together with the sending status.

16.2.3E-mail template

Used to design the template of e-mails to be sent automatically. With the parameters available in the Layout field, the content, text and signature of the e-mail can be customised. The CC and BCC fields can also be edited.

16.2.4Setting up the e-mail server

Setting up the sending server for the e-mails sent by Infinity. To enter the parameters, please ask for the help of the specialists operating your company's mail system.
