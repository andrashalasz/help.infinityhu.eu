6.2.1New product

Basic data

A new item can be created in Infinity in two ways: by bulk import or by manual entry. To create an individual item, go to Inventory → Products → Product list and click the Create button.

6.2.2Product list

In the header of the list you find the search field, the filters by type and the action buttons. The list shows, row by row, the identifier, name, type, list price and stock of the item, along with the actions.

Filters and search

The type pill filters (Product, Service, Raw material and so on) narrow the list immediately — only the types that actually exist appear.

The search field works with space = AND, comma = OR logic and accent-insensitive searching.

The Export button saves the filtered list to a CSV file.

Action buttons (per row)

  • 🗑 Delete — sets the product to inactive (does not delete it physically).

  • 👁 Quick view — shows the most important data of the product (price, stock, EAN, manufacturer, VAT) in a pop-up card. The full record can be opened from here.

  • ✏ Edit — opens the detailed record of the product in edit mode.

  • 📋 Copy — creates a copy with the item number suffix “-COPY”, in Inactive status; the copy is placed at the top of the list.

6.2.3Creating a new product – Basic data tab

Clicking the + Create button opens a modal window. On the Basic data tab, enter the master data of the item.

ℹ When the Type is selected, the form refreshes dynamically — for Service, the fields related to warehouse stock management (shelf number, minimum stock, unit packaging and so on) are hidden.

Special markers (check boxes)

  • Intermediated service — the item is the intermediation of a service provided by another party.

  • Delivery cost item — the item is placed on the invoice as a delivery charge.

  • Sale to order — the item is not delivered from stock but to order.

  • Unit packaging — the item can be sold in unit packaging.

  • Serial number tracking — when switched on, a unique serial number has to be given for the item at every movement.

Tags

On the Basic data tab you can assign tags to the item. Tags are free-word markers (for example On sale, New product, Seasonal). Entry: they are recorded after Enter or a comma; the system also offers predefined suggestions.

Multilingual name and description

Above the Name field there are language pill tabs (Base + added languages + Add language). On the Base tab, enter the name in the base language of the system; on the other tabs the translation for the given language can be recorded. The Description field on the Other tab works the same way.

6.2.4Product record

When the product is opened, a two-column view appears: on the left the header of the record and the related data, on the right the content broken down into tabs.

Header

  • A header with the type background colour, containing the monogram avatar, the name, the identifier and the item number of the item.

  • A type badge shows the type of the item.

  • A clickable Active/Inactive status pill — clicking it switches between the two states.

  • Special markers (for example Intermediated / Advance) are displayed separated by /.

Reading mode – tabs

  • Record — basic data, tags, values of the custom fields.

  • Financial data — pricing data, VAT, special markers. (Also accessible by clicking the related data card.)

  • Warehouse — shelf number, minimum stock, stock management settings. (Also accessible by clicking the related data card.)

  • Size & Weight — dimensions (X/Y/Z) and net/gross weight.

  • Other — service and customs tariff code, YouTube link, description, translations.

  • Custom fields — the values of the custom fields configured in the admin.

  • Images — the images uploaded for the item (drag & drop is also supported).

  • Prices — the list of selling price types, with validity dates.

  • Identifiers — foreign item numbers (below) and EAN barcodes (above).

  • VAT classification — VAT rates and validity periods, service code.

  • Categories — assignment of product tree categories.

  • Serial numbers — appears only for items with serial number tracking; it lists the serial numbers in stock.

Related data (cards on the left)

The related data section on the left contains three clickable cards. Clicking each of them opens a pop-up modal with a blue header:

  • Financial data — the pricing and financial data of the product.

  • Stock — the current warehouse stock broken down by site; with the 👁 button the warehouse movements can be displayed.

  • Related documents — the documents attached to the product; with the 👁 button a preview and the details can be displayed.

Change history

Clicking the All › link opens a pop-up modal showing the timeline of the changes to the product (name of the event, detail, date, user).

Sidebar buttons

  • ✏ Edit — switches to edit mode and jumps to the Record tab.

  • 🖨 Label — label printing modal: price type and currency selector, preview, Print button.

ℹ In edit mode, instead of the Label button a red Cancel button appears, with which the editing can be discarded.

6.2.5Edit mode

Clicking the ✏ Edit button makes the Record tab editable, and the editor tabs slide into the tab row at the top.

Tab row in edit mode

Record · Financial data · Warehouse · Size & Weight · Other · Custom fields · Images · Prices · Identifiers · VAT classification · Categories

⚠ For the Service type, the Warehouse and Size & Weight tabs do not appear.

Effect of changing the type during editing

If the Type field is changed during editing, the tabs and fields displayed refresh immediately and dynamically — switching to Service makes the stock-specific tabs and fields disappear.

Saving

The modifications can be finalised with the green 💾 Save button on the left of the sidebar.

6.2.6Managing custom fields

The admin screen of the custom fields is reached by clicking the ⚙ Custom fields button in the header of the product list.

Field definition

  • Field name — freely definable (for example Colour, Material, CE certificate).

  • Type — Text / Number / Yes-No / Date / List.

  • Appears for — All products / a given Type / a given Category.

  • Mandatory — if ticked, it has to be filled in when the product is saved.

ℹ The fields defined here are automatically available in the import column mapper (GET /api/import/fields?type=product endpoint).

6.2.7Barcode printing

The Label modal is accessible from the product record (or by opening it from the list with the ✏ button); after entering the price type and the currency, a preview is shown and the barcode can be printed with the Print button.

Two kinds of barcode can be used in Infinity:

  • Normal, single-price barcode.

  • Discount barcode — the original price crossed out, with the discounted price next to it.

The barcode type of the site can be specified in the site settings.

6.2.8Copying a product

Clicking the 📋 Copy button in the actions row of the list makes the system create a copy of the product:

  • Item number: the original item number + the suffix “-COPY”.

  • Status: Inactive (it does not go on sale automatically).

  • All other data (prices, images, identifiers and so on) are inherited.

  • The copy is placed at the top of the list.

6.2.9Product variants

If you have many essentially identical items — differing only in one property — the size of the product master data can be reduced by creating product variants. The variants are subordinated to the main product.

Product variants receive a unique, configurable item number: the item number of the main product is supplemented with the variant code. Every variant inherits the data of the main product, but it can also have a different price.

Goods receipt with variants:

  • When receiving the main item: all assigned variants can be received at once, at the same purchase price, with a quantity per variant

  • With variant-level receipt: the quantity and the purchase price are given individually

Only the product variants can be sold, not the main item. At stocktaking you can take stock of the main product, or you can do it separately per variant.

First define the distinguishing properties (for example colour, size) as product attributes:

Then create the individual product variants. For example for products in different colours: add every possible colour as an attribute, create the main product, and the system then generates the new item number per variant.

Both the product attributes and the product variants can be extended at will. At goods receipt you can choose from the following options:

  • Receive the main item (same price, quantity per variant)

  • Receive the variants one by one (individual price and quantity per variant)

Note

Only the product variants can be sold, not the main item.

6.2.10Product history

For products with serial number management, the movements related to the product can be listed by entering the serial number; otherwise by entering the item number.

6.2.11Bulk pricing

If you want to change the price of several products at once, the Bulk pricing menu helps. When the menu is opened, every product is listed — you can filter them, or select the ones to be modified manually.

Clicking the Select button displays the price modification screen, where the new prices can be entered quickly.

If you have selected an item whose price you do not want to change after all, you can remove it from the list with the orange bin at the beginning of the row. If a minimum or maximum price has been given for the item, these are displayed as guidance.

If you want to modify several price types at once (for example the forint and euro list price), add a New price type — the system changes both at the same time. The price modification is finalised by saving.

6.2.12Bulk pricing from a file

For price changes in large volumes, an Excel-based import is also possible.

After downloading the sample file, enter the item number and the new price. In the Pricing window on the right, specify the currency, the price type and the validity date.

Clicking the upload button loads the prices temporarily (this does not overwrite the existing ones yet). If you are satisfied with the result, click the Save all changes button.

6.2.13Creating a price list

You can create a price list from the existing products for your partners. Select the products, add them to the list with the Select button, then export them in the required currency and price type.
