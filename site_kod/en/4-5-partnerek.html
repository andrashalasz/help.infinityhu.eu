Partners

Updated 2026.08.26 · v2026.08.26

The partner master data stores the partners available to the whole system: customers, suppliers, business contacts (contact persons, freight forwarders) and store networks. The basic settings related to partners can also be made in this module.

4.5.1Settings

In the Settings menu you can manage the following master data:

  • Salutations, titles

  • Street types

  • Postcodes (also assigned to towns)

  • Points of sale

  • Transfer deadlines (deadlines available for deferred invoicing)

Partner groups

You can create groups from the partners recorded in the system. The groups can be used in commercial reports or in the CRM system. You can also create partner group categories, which help in the CRM and in customer service tasks.

Loyalty cards

Infinity can also manage a loyalty programme. Create a loyalty card in the system, fill in the parameters (discount, partner assignment), and when the code is entered at the point of sale the system automatically handles the discounts and the collection of points.

4.5.2Partner list

Creating a partner

Status

When creating a new partner, using the default status is recommended. Partners with the default status count as active, can be modified, and documents can be recorded against them.

Note

A partner cannot be deleted, only its status can be changed. No new document can be recorded against a partner with deleted status. The changes do not affect the data of invoices issued earlier.

Type

You can choose from five partner types:

  • Private individual — only the full name and the billing address are mandatory

  • Company — a Hungarian tax number is mandatory; the system validates the tax number both when recording and when issuing an invoice

  • Foreign company — the EU VAT number is sufficient

  • Sole trader — a Hungarian tax number is mandatory

  • Employee — beyond the normal partner data, the data required for the employment relationship and payroll can also be recorded

Tax number validation

The system validates both when recording (format correctness, duplicate) and when issuing an invoice (real, live tax number). An invoice can only be issued to a partner with a valid tax number.

Registration

Filling in the registration controls which partner lists the partner appears in when documents are created. A partner can belong to several categories at the same time (for example, both customer and supplier).

Possible registration categories: Customer, Supplier, Employee, Contact person, Freight forwarder, Pick-up point, Drop-off point.

Payment deadline

The payment deadline typical of the given partner. The system uses this for invoice-based sales. In individual cases it can be overridden when the invoice is issued.

E-invoice

For a partner flagged for e-invoicing, the system automatically issues an electronic invoice. You can return to paper-based invoicing by clearing the flag.

Price type

The custom price types created in the system can be assigned to the partner here.

Adding a new customer or supplier

Click the New partner button, select the type (company, sole trader, private individual) and fill in the data.

Fields marked with a red asterisk are mandatory. Several of the Registration cells can be selected at the same time.

For a private individual:

Postal address

If a separate postal address is required, tick the “Postal address differs from the registered office” box — the input fields then appear.

Modifying partner data

The partner selected from the partner list can be viewed with the eye button and modified with the pencil button. You can record the partner's sites, contact details and contact persons.

Note

If the customer's address changes, it does not change on invoices already issued — the new address appears only on invoices issued afterwards.

Sites

For partners with several sites, the sites can be recorded after displaying the partner, on the Sites tab of the Contact details menu, using the Create button.

The most important data of a new site:

  • Site name

  • Address: the exact address of the site

  • Status: only active sites can be selected in the various menus

  • Barcode type: you can set which of the two default barcodes the given site uses

  • Original price on the barcode: the selected price type appears on the barcode as the original price

  • Discounted price on the barcode: filled in only for discount barcodes

  • KTJ number: the unique environmental area identifier of the site

  • GLN: the physical location identifier of organisations registered with GS1

  • Main site: used to mark the registered office (at least one main site is required for every partner)

Partner current account

When the partner is displayed, the items on the current account, the payments in and out and the open invoices are immediately visible. The data can be filtered by current account, document and payment status. The documents and their items can also be displayed.

Bank accounts

Used to record your own and the partner's bank accounts. For international bank accounts, the IBAN and the SWIFT code are mandatory. The default bank account number is suggested when a payment batch is assembled.

Contact details

Used to record the partner's contact details. In the case of an electronic invoice, the invoice is sent to the e-mail address given here or at the site.

Contact person

An unlimited number of contact persons can be assigned to a partner, specifying the type of contact detail.

Current account

The partner's current account balance — per invoice or per item — along with the payments and the open invoices can be found on the Current account worksheet. The invoices can be opened and modified with the action buttons.

4.5.3Importing partners

The Import partners menu allows partner data to be entered in bulk.

Download the sample file and prepare the import table in Excel.

Caution

Do not delete any sheet, field or cell from the downloaded Excel file, otherwise the import will fail.

The column headers help with filling in the file. Where an option is marked with a number (for example at the status), it is enough to enter the number. To fill in the country, use the last sheet of the Excel file, Countries — copy the country name from there, because the system cannot interpret a different spelling.

To import, select the saved file with the Select button, then upload it with the Import button.

Note

Only import data that has been checked: the system rejects only data that is formally incorrect; data that is incorrect in substance has to be corrected manually.

After the import, an information table reports on how the import went. Items that are formally incorrect can be exported to Excel, corrected and imported again.
