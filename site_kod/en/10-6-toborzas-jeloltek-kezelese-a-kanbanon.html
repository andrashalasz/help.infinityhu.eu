Recruitment – managing candidates on the Kanban

Updated 2026.08.26 · v2026.08.26

Menu: HR → Recruitment

In the Recruitment module the candidates appear in a list view. The Kanban view helps you see where the selection stands.

10.6.1Recording a new candidate

You can record a new candidate in the HR → Recruitment menu with the “Create” button. After saving, the candidate is automatically placed in the “Received” status.

  1. Click: New candidate.

  2. Select the position (only a position with the status Open or In progress can be chosen).

  3. Enter the candidate's name and at least one contact detail (e-mail or phone).

  4. Set the source and the status.

  5. Upload a CV (PDF, max. 10 MB) if one is available.

  6. Fill in the details of the application and the special data if needed.

  7. Save.

    Basic data

Field Type Mandatory? Explanation / tips
Position Drop-down Yes The candidate is always tied to a position. Only a position with the status Open or In progress can be selected.
Candidate's name Text Yes The identifying data of the candidate; this is what appears in the lists and on the Kanban.
E-mail E-mail No The duplicate warning is based on the e-mail address.
Phone Text No Alternative contact detail.
Source Drop-down Yes Where the candidate came from. Needed for reports and for measuring channel efficiency. Loaded from the master data under Settings → Onboarding settings → Source.
Status Drop-down Yes The current pipeline step of the candidate. Loaded from the master data under Settings → Onboarding settings → Candidate status.

Related data

Field Type Mandatory? Explanation / tips
CV / file upload File No Only PDF files are accepted, max. 10 MB. It can be uploaded by drag & drop or with the Browse button.
LinkedIn URL No The link to the candidate's LinkedIn profile.
Facebook URL No The link to the candidate's Facebook profile.
Instagram URL No The link to the candidate's Instagram profile.

Details of the application

Field Type Mandatory? Explanation / tips
Seniority Drop-down No The level requested by or attributed to the candidate (for example junior, medior, senior).
Salary expectation min Number No The minimum salary expectation indicated by the candidate.
Salary expectation max Number No The maximum salary expectation indicated by the candidate.
Currency Drop-down No The currency of the salary expectation (for example HUF, EUR).
Availability / starting date Date No The earliest date the candidate could start.
Comment for internal use Long text No Only HR and the manager see it; negotiation points, impressions.

Special data

Field Type Mandatory? Explanation / tips
Tech stack Multi-select No The technologies known by the candidate. A particularly useful filtering and comparison dimension in IT recruitment.
English level Drop-down No The level of the candidate's English (for example A1–C2, or basic/intermediate/advanced).
Remote work preference Check box No It indicates whether the candidate prefers remote work.
Test assignment status Drop-down No The current state of the test assignment given to the candidate (for example issued, received, evaluated).

10.6.2Moving the candidate's status on the Kanban

On the Kanban you can move the candidates by drag & drop. Every move is recorded in the status history, so it can be traced back when the candidate stood at which step.

  1. Open the relevant position with a filter (if several positions are running).

  2. Grab the candidate card and drag it into the next column (for example Received → Pre-screened).

  3. If the system asks for a comment (for example at a rejection), enter the reason.

  4. Check the badges on the candidate card (for example “Interview scheduled”).

10.6.3Recording and closing interviews

You can add an interview on the candidate's record. When recording the interview, you enter the time, the type (see: 3.6.4 Interview type) and the participants.

  1. Open the candidate (click the card).

  2. Go to the “Interviews” section and click: Schedule interview.

  3. Select the type (HR/tech/final), set the time and the participants.

  4. After saving, the status of the interview is Scheduled.

  5. After the interview, open it, set it to DONE and enter the evaluation.

Field Type Mandatory? Explanation / tips
Interview type Enum Yes HR/tech/final; useful for reports as well.
Time Date + time Yes The basis of the calendar view and the reminders.
Meeting link / location Text/URL No An online link or an office location.
Participants User list Yes Who conducts the interview; the load is visible.
Comments Text No Comments related to the interview

10.6.4Creating and tracking an offer

When the selection is successful, you create an offer. The offer is a separate record, because this way it can be tracked (sending out, acceptance, expiry) and reported on later.

  1. Candidate record → Offer section → Create offer.

  2. The position is filled in automatically from the candidate's record.

  3. Enter the opening date and the type of employment.

  4. Fill in the compensation data (base salary, currency, pay period).

  5. Tick the benefits granted (laptop, phone, home office allowance, company car, other).

  6. If needed, enter the validity date and the internal comment.

  7. Attach a PDF document if necessary.

  8. Save — the offer is recorded with the status Draft.

    Basic data

Field Type Mandatory? Explanation / tips
Position Text (read-only) – Filled in automatically from the candidate's record; it cannot be edited.
Opening date Date Yes The date the offer was drawn up.
Employment Drop-down Yes The type of employment (for example full-time, part-time). Loaded from the master data under Settings → Job and employment → Type of employment.
Status Status label – For a new offer it is automatically Draft. After saving it can be moved on manually.

Administrative data

Field Type Mandatory? Explanation / tips
Validity date Date No How long the offer is valid. For monitoring the expiry; the system can give an alert.
Comment for internal use Long text No Only HR and the manager see it; negotiation points, internal context.
Attachment (PDF only) File No For attaching the offer letter or the draft contract.

Compensation

Field Type Mandatory? Explanation / tips
Base salary Number No The gross base salary offered to the candidate. A permission-dependent field — only HR/Finance can see it.
Currency Drop-down Yes The currency of the base salary (for example HUF, EUR).
Pay period Drop-down Yes The frequency of the base salary (for example monthly, annual).
Bonus Number No The amount of the performance-based or other bonus.
Benefits Check box list No Several items can be selected: laptop / phone / home office allowance / company car / other.

10.6.5Hiring – when and how

Accepting the offer is not yet hiring. Hiring is an HR approval step that creates the employee in the system, updates the headcount of the position and starts the onboarding.

  1. Candidate status: Offer accepted

  2. On the Kanban list, click on the candidate's record:

  3. The system sends out the employee data sheet

  4. The employee fills it in, uploads the necessary documents and saves — at this point they are created as a “partner” in Infinity.

  5. Check and complete the entry data (start date, manager, contract type, salary and so on).

  6. Finalise the hiring: the partner has to be converted into an employee, and an onboarding template — created in the settings — has to be assigned if needed.

  7. Check: the employee appears among the Employees, the onboarding has started.
